Game clock mod — Scripts (local only)
=====================================

The Lua source (main.lua) is NOT in the public Git repository.

Restore from a local backup under `secret/` (see `secret/README.txt`), or from the
local-only Git branch `local/backup-with-gameclock-mod` (never push to origin).

After copying, enable the mod per your external timing provider setup.

See docs/TIMING_OPERATING_MODES.md for how acr_timing consumes acr_game_clock.jsonl.
